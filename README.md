# Web Designer 150K — 90 Day Challenge

Адаптивное приложение-планировщик для выхода веб-дизайнера на цель **150 000 ₽/мес за 90 дней**.

## Что внутри

- Dashboard с финансовой целью и прогрессом
- ежедневные revenue actions
- 90-дневный план
- CRM и воронка клиентов
- портфолио из 5 проектных направлений
- программа обучения
- аналитика
- сохранение прогресса в localStorage
- адаптивная верстка для desktop, tablet и mobile
- мобильная нижняя навигация
- safe-area поддержка для iPhone

## Запуск

Открой index.html локально или включи GitHub Pages для репозитория.

Приложение не требует backend для базовой работы.
